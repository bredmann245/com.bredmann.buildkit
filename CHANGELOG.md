# Changelog

## [0.3.0] - 2026-11-15

- Face snap: point at a placed module and the ghost sits flush against that face
- Slide along the face in module steps from the target edge; Shift half step, Ctrl free
- Snap mode Grid / Auto / Face, key G cycles, orange outline on the target face

## [0.2.0] - 2026-11-15

- Scene feedback: green shared faces, red overlaps, grid overlay, level marker, cell label
- Skip occupied cells option for Place, Line and Fill
- Module count while dragging Line and Fill

## [0.1.0] - 2026-11-15

- Initial release
- BuildModule component and bounds analyzer
- Place, Line and Fill scene tools with grid snapping
- Stack and Bake utilities
- BuildKit editor window with variants and hotkeys
